# Text Query

## Project Introduction

This project is a C++-based text query system that supports word queries and composite queries (AND, OR, NOT) on text files.

## Main Features
- Support for single word queries
- Support for composite queries: AND, OR, NOT
- Display query results with line numbers and context
- Query history management

## File Structure
- `main.cpp`: Main program entry
- `TextQuery.h`: Core class for text querying
- `Query.h` and related: Query expression related classes
- `History_manager.h`: Query history management
- `exmple.txt`: Example text file

## Build and Run

1. Open the `Text Query.sln` solution with Visual Studio 2022.
2. Build and run the project.
3. Enter query commands as prompted by the program.
